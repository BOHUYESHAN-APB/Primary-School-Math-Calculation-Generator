
# 小学数学题目生成器 - 技术架构设计

## 系统概述

本应用是一个跨平台的桌面应用程序，采用 Electron + React + TypeScript 前端与 Python FastAPI 后端相结合的架构，专门为小学数学题目生成和AI辅助解答设计。

### 2. 预加载脚本 (`electron/preload.js`)

**安全桥梁设计**:
```javascript
contextBridge.exposeInMainWorld('electronAPI', {
  // 菜单事件监听（返回unsubscribe函数）
  onMenuAction: (callback) => {
    const channels = ['menu-new-questions', 'menu-export-pdf', ...];
    const handlers = channels.map(ch => {
      const handler = (_event, ...args) => callback(ch, ...args);
      ipcRenderer.on(ch, handler);
      return { ch, handler };
    });
    
    return () => handlers.forEach(({ ch, handler }) => 
      ipcRenderer.removeListener(ch, handler));
  },
  
  // MCP服务器管理
  startMCPServer: () => ipcRenderer.invoke('mcp-server:start'),
  stopMCPServer: () => ipcRenderer.invoke('mcp-server:stop'),
  
  // 终端管理
  createTerminal: (options) => ipcRenderer.invoke('terminal:create', options),
  // ... 其他API
});
```

## 通信协议设计

### 1. 进程间通信 (IPC)

**Electron 主进程 ↔ 渲染进程**:
- 通道: `menu-*`, `terminal:*`, `mcp-server:*`
- 模式: `ipcRenderer.invoke()` + `ipcMain.handle()`
- 事件: `ipcRenderer.on()` + `webContents.send()`

**前端 ↔ Python MCP服务器**:
- 协议: HTTP REST API
- 端口: 8002
- 认证: 本地通信，无需认证

### 2. 数据流设计

**配置加载流程**:
```
前端组件 → electronAPI → 主进程IPC → Python MCP进程 → 
FastAPI (/api/config) → config_loader → YAML文件
```

**AI分析流程**:
```
前端输入 → electronAPI (startMCPServer) → 主进程启动Python → 
FastAPI (/ai/analyze) → AI服务调用 → 返回结构化结果
```

## 安全架构

### 1. 内容安全策略 (CSP)
```javascript
'Content-Security-Policy': [
  "default-src 'self'; " +
  "script-src 'self' 'unsafe-inline'; " +
  "style-src 'self' 'unsafe-inline'; " +
  "img-src 'self' data:; " +
  "font-src 'self' data:; " +
  "connect-src 'self' http://localhost:8002 http://127.0.0.1:8002"
]
```

### 2. 进程隔离
- `nodeIntegration: false` - 禁用Node.js集成
- `contextIsolation: true` - 启用上下文隔离
- 预加载脚本作为唯一的安全桥梁

### 3. 代码执行安全
```python
def is_code_safe(code: str) -> bool:
    # 禁止危险模块和函数
    forbidden_patterns = [
        'import os', 'import sys', 'import subprocess',
        'os.', 'sys.', 'subprocess.', '__', 'exec', 'eval'
    ]
    return not any(pattern in code for pattern in forbidden_patterns)
```

- **终端进程管理**: 验证进程生命周期管理
